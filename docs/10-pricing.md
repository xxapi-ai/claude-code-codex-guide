# xxapi 怎么算费用：「约官方价 X%」是什么意思

xxapi（[https://xxapi.ai](https://xxapi.ai)）按用量扣费，没有月费：充值时付 ¥1 到账 $1，每次请求按模型在你密钥所在分组的美元单价，从余额里扣。分组卡片上的「约官方价 X%」，意思是同样的用量，用这个分组实际付的钱约是按模型官方美元标价付费的 X%。每个模型的具体单价以 [模型广场](https://xxapi.ai/pricing) 和 [价格表](https://docs.xxapi.ai/pricing) 为准，本文不写具体数字，因为价格会调整。

## 1. 扣费由什么决定

- **分组**：一枚 API 密钥（API Key）只属于一个分组，只按这个分组的价格扣费。同一个模型在不同分组的单价不同，分组越贵，「约官方价」的比例越高。
- **模型**：文字模型按每百万 tokens 计价，分输入、输出、缓存读取，Claude 模型还有缓存写入；生图模型按张计价。
- **用量**：每次请求实际用了多少 tokens 或生成了几张图。

## 2. 价格表里的几个词

- **输入**：这次请求发给模型的内容里，除去缓存读取和缓存写入的部分。
- **输出**：模型写出的内容，包括思考过程。
- **缓存读取**：和之前请求开头相同、已经缓存过的内容，比输入便宜得多。长对话里大部分输入都能按缓存读取计价。
- **缓存写入**：第一次把内容存进缓存。Claude 模型有 5 分钟和 1 小时两种，价格不同；GPT 模型不收这一项。
- **输入长度**：少数模型在一次请求的输入很长时按更高的一档计价，按整次请求的输入算。

## 3. 「约官方价 X%」怎么算

xxapi 的余额按美元计，充 ¥1 得 $1；直接向官方付费是按美元付，$1 约合 ¥7。所以：

```text
约官方价 X% ≈ （价格表里的美元单价 × ¥1） ÷ （官方美元单价 × ¥7）
```

举个示意的例子（数字不是真实价格）：某模型官方标价每百万输入 tokens $4，在某个分组写 $10。在 xxapi 实际付约 ¥10，向官方付约 ¥28，¥10 ÷ ¥28 ≈ 35.7%，这个分组就写「约官方价 36%」。

同一个分组里，每个模型相对官方价都是同样的倍数，所以控制台只在分组上写一次比例。

为什么是“约”：

- 官方价按 $1 约 ¥7 换算，实际汇率会变。
- 显示时只入不舍：10% 以下保留一位小数，10% 以上取整数，都向上取，不会让分组看起来比实际更便宜。

生图分组按张收费，和官方按 token 的计价方式不同，所以直接写每张多少美元，不写百分比。

## 4. 实际扣了多少

每次请求的用量和扣费，以 [使用日志](https://xxapi.ai/usage-logs/common) 为准。付款方式、最低充值金额和到账比例以 [钱包](https://xxapi.ai/wallet) 页面为准。

## 5. 怎么省钱

- 同一个对话尽量只用一个模型，换模型会让缓存从头开始。
- 对话太长时用 `/compact` 压缩或新开对话，既能避免 prompt is too long，也能避免按高一档的输入长度计价。
- Claude Code 和 Codex 各用一枚密钥，在使用日志里能分别看到各花了多少。
